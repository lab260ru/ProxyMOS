# MOS Research

This repository contains the experimental codebase behind the paper **"ProxyMOS: Training Speech Quality Models via Ensemble-Derived MOS Targets"**. It provides all the infrastructure for evaluating non-intrusive MOS prediction models, running ensemble experiments, and training ProxyMOS via knowledge distillation from aggregated model outputs.

> Borodin K., Trokunov M. — MTUCI, Moscow, 2026

---

## What's inside

The repo covers the full pipeline described in the paper:

- Evaluation of seven non-intrusive MOS prediction models on URGENT and mos260 benchmarks
- Systematic ensemble search across all model subsets and aggregation strategies
- Adaptive routing via a learned MLP that assigns per-sample predictor weights
- Generation of ensemble-derived MOS targets on large-scale unlabeled corpora
- Training of ProxyMOS — a single distilled model built on top of OmniASR-W2V-300M

## Models evaluated

All seven models from the paper are supported:

| Model | Architecture | Domain |
|---|---|---|
| MOSNet | CNN + BLSTM on spectrograms | General |
| NISQA | CNN + Self-Attention | Degraded / noisy speech |
| DNSMOS | Lightweight model following ITU-T P.835 | Speech enhancement |
| UTMOS | SSL-based, fine-tuned for TTS evaluation | TTS / VC |
| DistillMOS | WavLM representations + MOS regression | General |
| HuBERT-MOS | HuBERT embeddings | General |
| WhiSQA | Whisper encoder representations | General |

## ProxyMOS

ProxyMOS is the distilled model trained on ensemble-derived MOS targets generated by the best-performing model subset (WhiSQA + DistillMOS + UTMOS + XLS-R). It is built on top of an OmniASR-W2V-300M encoder with attentive statistics pooling and a two-layer regression head.

Pretrained weights are available at [assskelad/proxymos](https://huggingface.co/assskelad/proxymos).

**Results on held-out benchmarks:**

| Benchmark | Spearman ρ | Pearson r | RMSE |
|---|---|---|---|
| URGENT | 0.802 | 0.806 | 0.471 |
| mos260 (Russian TTS) | 0.647 | 0.700 | 0.883 |

ProxyMOS outperforms all individual teacher models on both benchmarks.

## Datasets

| Dataset | Size | Labels | Role |
|---|---|---|---|
| URGENT | 6,400 | ✓ | Train / Test |
| BVCC | 3,000 | ✓ | Train (routing) |
| SOMOS | 20,000 | ✓ | Train (routing) |
| mos260 | 4,600 | ✓ | Test only (Russian TTS) |
| MLAAD | 200,000 | ✗ | Ensemble target generation |
| OpenSTT | 440,000 | ✗ | Ensemble target generation |
| SpeechFake | 167,573 | ✗ | Ensemble target generation |

**mos260** is a new Russian TTS evaluation dataset introduced as part of this work, annotated via crowdsourcing using the [LabelSpeech](https://github.com/mtuciru/LabelSpeech) platform.
